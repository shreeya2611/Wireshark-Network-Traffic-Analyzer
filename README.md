# README: Network Traffic Analysis Using Wireshark

## Project Title

Network Traffic Analysis Using Wireshark

## Objective

The objective of this project is to capture and analyze network traffic using Wireshark to understand how data travels between devices on a network.

## Problem Statement

Use Wireshark to capture network packets and analyze network traffic to identify communication between devices, protocols, and data transmission patterns.

## Tools Required

* Wireshark
* Windows 11
* Internet connection

## Implementation Steps

### Step 1: Install Wireshark

Download and install Wireshark on your Windows system.

### Step 2: Open Wireshark

Launch the Wireshark application from the Start menu.

### Step 3: Select a Network Interface

Choose the active network interface:

* Wi-Fi
* Ethernet

### Step 4: Start Capturing Packets

Click the network interface and select the blue shark-fin icon to begin capturing network traffic.

### Step 5: Generate Network Traffic

Open a web browser and perform activities such as:

* Visiting websites
* Searching on Google
* Opening web applications
* Refreshing web pages

### Step 6: Stop Packet Capture

Click the red stop button to stop capturing packets.

### Step 7: Apply Filters

Use Wireshark filters to analyze specific traffic.

Examples:

```bash id="mtzk4u"
http
```

```bash id="1gq0vh"
tcp
```

```bash id="k5ez4w"
udp
```

```bash id="7b85lv"
dns
```

### Step 8: Analyze the Captured Packets

Examine the following information:

* Source IP address
* Destination IP address
* Protocol
* Packet length
* Transmission time

## Results

The network traffic was successfully captured and analyzed using Wireshark. Different protocols, including TCP, UDP, DNS, and HTTP, were identified during packet analysis.

## Applications

* Network monitoring
* Troubleshooting
* Security analysis
* Protocol analysis
* Performance monitoring

## Conclusion

This project successfully demonstrated how Wireshark can be used to capture and analyze network traffic. Packet analysis helps identify communication between devices and provides a better understanding of network behavior.
